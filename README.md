# RHI Beta

Test builds of **RHI (ReShade HDR Installer)**. The source code and stable releases are in [RankFTW/RHI](https://github.com/RankFTW/RHI).

## Getting betas

In RHI, open **Settings › General › Updates** and turn on **Get beta updates**. RHI then offers each new beta from this repo. When the full release of that version comes out, RHI moves you to it.

Turning the setting off doesn't downgrade you: you stay on the beta until the next full release.

## Installing by hand

Download `RHI-Setup.exe` from the latest release here. It installs over your current RHI and keeps your settings.

Betas are test builds and can have bugs. Please report problems on the RHI Discord or in [RankFTW/RHI issues](https://github.com/RankFTW/RHI/issues), and say which beta you're on.
